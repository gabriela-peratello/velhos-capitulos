📖 Sebo Digital: Velhos capítulos
Este é um projeto desenvolvido em colaboração para gerenciar e visualizar um acervo de livros usados. A aplicação combina uma interface responsiva com interações dinâmicas para oferecer a melhor experiência ao usuário.

🚀 Tecnologias Utilizadas
O projeto foi construído utilizando o quarteto clássico do desenvolvimento web moderno:

HTML5: Estruturação semântica do conteúdo.

CSS3: Estilização personalizada e layouts fluidos.

JavaScript (ES6+): Lógica de manipulação do DOM e dinamismo.

Bootstrap 5: Framework de CSS para garantir que o site seja 100% responsivo.

SweetAlert2: Substituição dos alertas nativos do navegador por pop-ups elegantes e interativos.

🛠️ Funcionalidades
Catálogo Responsivo: Visualização de livros em formato de cards que se adaptam a qualquer tela.

Alertas Customizados: Uso do SweetAlert para confirmações de compra, mensagens de erro ou notificações de sucesso.

Filtros de Busca: Sistema de pesquisa rápida por título ou autor.

Carrinho de Compras: Adição e remoção de itens com feedback visual imediato.
